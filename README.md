# website

Source of the website of Sovereign Infrastructure Software Lab, LLC (SISL), published at https://sovereigninfralab.com once the domain is registered.

## How it is built

The published site is plain HTML and CSS in `site/`, committed as is. There is no JavaScript, no third-party request and no package dependency, so there is nothing to install and no package supply chain to maintain. Cloudflare Pages serves `site/` without a build step.

- Page text lives in `src/pages/` (one file per page: three header lines, `---`, then the page body).
- `tools/build.py` (Python 3 standard library only) wraps each page in the shared header and footer and writes `site/`, including `sitemap.xml`. After editing a page or the navigation, run `python3 tools/build.py` and commit both `src/` and `site/`.
- Shared styles: `site/css/site.css`. Fonts (IBM Plex Sans Condensed and Source Serif 4, SIL Open Font License) are self-hosted in `site/fonts/` with their licenses.
- The home-page traffic diagram is generated by `tools/diagram.py` into `src/partials/edge-diagram.html` and included in the home page with `<!-- include: edge-diagram -->`. Run `python3 tools/diagram.py` before `tools/build.py` if you change it.
- `site/_headers` sets the security headers (HSTS, Content Security Policy and others) on Cloudflare Pages.
- `site/.well-known/security.txt` is the security contact (RFC 9116). Renew its `Expires` date before it lapses.

## Deploying (Cloudflare Pages)

- Connect this repository in Cloudflare Pages.
- Production branch: `main`. Framework preset: None. Build command: leave empty. Build output directory: `site`.
- Add the custom domains `sovereigninfralab.com` and `www.sovereigninfralab.com`, and redirect `www` to the apex with a Cloudflare redirect rule.

## Previewing locally

```sh
python3 -m http.server --directory site 8000
```

Then open http://localhost:8000. (The local server does not apply `_headers`.)
